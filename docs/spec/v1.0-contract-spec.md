# Escrow Protocol — Contract Spec v1.0

**Version:** v1.0  
**Status:** Draft (validated, ready for implementation)  
**Scope:** Single-chain, single-token (USDC), no fees, no arbitration, no upgrades, no UI required.

## 1. PURPOSE

This contract implements a simple escrow flow between:

- **Client**: creates and funds a deal, can release funds or refund after deadline, can cancel before funding.
- **Provider**: can mark work as delivered (optional informational step).

Funds are held by the contract in an ERC20 token (USDC) and are released or refunded based on strict state transitions.

## 2. ROLES

- **client**: the payer and deal owner.
- **provider**: the recipient of funds upon release.
- **owner** (admin): exists only to rescue non-escrow tokens accidentally sent to the contract; has no control over deals or escrow funds.

## 3. TOKEN SUPPORT (v1.0)

- The contract supports exactly one ERC20 token address defined at deployment time: `PAYMENT_TOKEN`.
- All deals are denominated in `PAYMENT_TOKEN` only.
- `amount` is expressed in token smallest units (USDC: 6 decimals).
- Assumption: `PAYMENT_TOKEN` behaves as a standard ERC20 without transfer fees (USDC-like).

**Important limitation (intentional):**

- Direct transfers of `PAYMENT_TOKEN` to the contract address (not via `fundDeal`) are NOT recoverable in v1.0.

## 4. DATA MODEL

### 4.1 DealStatus enum

```solidity
DealStatus:
- Created   (deal exists, not funded)
- Funded    (funds transferred into escrow)
- Delivered (provider marked delivered; optional)
- Released  (funds paid to provider; final)
- Refunded  (funds returned to client; final)
- Canceled  (canceled before funding; final)
```

### 4.2 Deal struct (storage)

```solidity
Deal:
- address client
- address provider
- uint256 amount
- uint64  createdAt
- uint64  releaseDeadline
- DealStatus status
- bytes32 metadataHash (optional offchain metadata hash, can be 0x0)
- bytes32 deliverHash (optional delivery proof hash, can be 0x0)
```

**Notes:**

- `createdAt` is set at creation.
- `releaseDeadline` is the timestamp at/after which refund becomes available.
- `deliverHash` is set only when provider calls `markDelivered`.

### 4.3 Storage

```solidity
- mapping(uint256 => Deal) public deals;
- uint256 public nextDealId; (starts from 1)
- address public immutable PAYMENT_TOKEN;
- address public owner; (set to deployer)
```

## 7. PUBLIC / EXTERNAL FUNCTIONS

### 7.1 constructor

```solidity
constructor(address paymentToken)
```

**Requirements:**

- `paymentToken != address(0)`

**Effects:**

- `PAYMENT_TOKEN` set immutable
- `owner = msg.sender`
- `nextDealId = 1`

### 7.2 createDeal

```solidity
function createDeal(
  address provider,
  uint256 amount,
  uint64 releaseDeadline,
  bytes32 metadataHash
) external returns (uint256 dealId)
```

**Caller:**

- `client = msg.sender`

**Requirements:**

- `provider != address(0)`
- `provider != msg.sender`
- `amount > 0`
- `releaseDeadline > block.timestamp`

**Effects:**

- `dealId = nextDealId; nextDealId++`
- `deals[dealId] = Deal({...})` with:
  - `client: msg.sender`
  - `provider: provider`
  - `amount: amount`
  - `createdAt: uint64(block.timestamp)`
  - `releaseDeadline: releaseDeadline`
  - `status: Created`
  - `metadataHash: metadataHash`
  - `deliverHash: 0x0`

**Events:**

- `DealCreated(dealId, client, provider, amount, releaseDeadline, metadataHash)`

### 7.3 fundDeal

```solidity
function fundDeal(uint256 dealId) external
```

**Caller:**

- must be `deal.client`

**Requirements:**

- deal exists
- `msg.sender == deal.client`
- `deal.status == Created` (else `WrongStatus(Created, actual)`)

**Effects:**

- transfer `PAYMENT_TOKEN` from client to contract for `deal.amount`
  (must use SafeERC20 / `transferFrom`)
- `deal.status = Funded`

**Events:**

- `DealFunded(dealId, client, amount)`

### 7.4 markDelivered (optional informational step)

```solidity
function markDelivered(uint256 dealId, bytes32 deliverHash) external
```

**Caller:**

- must be `deal.provider`

**Requirements:**

- deal exists
- `msg.sender == deal.provider`
- `deal.status == Funded` (else `WrongStatus(Funded, actual)`)
- `deliverHash != 0x0`

**Effects:**

- `deal.deliverHash = deliverHash`
- `deal.status = Delivered`

**Events:**

- `DealDelivered(dealId, provider, deliverHash)`

**v1.0 Rule for deliverHash:**

- Exactly one delivery submission is allowed (only from `Funded -> Delivered`).

### 7.5 release

```solidity
function release(uint256 dealId) external
```

**Caller:**

- must be `deal.client`

**Requirements:**

- deal exists
- `msg.sender == deal.client`
- `deal.status` is `Funded` OR `Delivered`
  (if not, revert `InvalidStatus(actual)`)

**Effects:**

- `deal.status = Released`
- transfer `PAYMENT_TOKEN` from contract to `deal.provider` for `deal.amount`
  (SafeERC20 / `transfer`)
- no fees

**Events:**

- `DealReleased(dealId, client, provider, amount)`

### 7.6 refund

```solidity
function refund(uint256 dealId) external
```

**Caller:**

- must be `deal.client`

**Requirements:**

- deal exists
- `msg.sender == deal.client`
- `deal.status` is `Funded` OR `Delivered`
  (if not, revert `InvalidStatus(actual)`)
- `block.timestamp >= deal.releaseDeadline`
  (else `RefundTooEarly(now, releaseDeadline)`)

**Effects:**

- `deal.status = Refunded`
- transfer `PAYMENT_TOKEN` from contract to `deal.client` for `deal.amount`

**Events:**

- `DealRefunded(dealId, client, amount)`

### 7.7 cancel

```solidity
function cancel(uint256 dealId) external
```

**Caller:**

- must be `deal.client`

**Requirements:**

- deal exists
- `msg.sender == deal.client`
- `deal.status == Created` (else `WrongStatus(Created, actual)`)

**Effects:**

- `deal.status = Canceled`

**Events:**

- `DealCanceled(dealId, client)`

## 9. OWNER / ADMIN FUNCTIONS (v1.0 minimal)

### 9.1 changeOwner

```solidity
function changeOwner(address newOwner) external
```

**Requirements:**

- `msg.sender == owner`
- `newOwner != address(0)`

**Effects:**

- `owner = newOwner`

**Events:**

- `OwnerChanged(oldOwner, newOwner)`

### 9.2 rescueToken (safety)

```solidity
function rescueToken(address token, address to, uint256 amount) external
```

**Purpose:**

- Rescue tokens accidentally sent to the contract that are NOT escrow payment token.

**Requirements:**

- `msg.sender == owner`
- `to != address(0)`
- `token != address(0)`
- `token != PAYMENT_TOKEN` (cannot rescue escrow payment token in v1.0)

**Effects:**

- transfer `token` to `to` for `amount`

**Events:**

- `TokenRescued(token, to, amount)`

## 10. STATE MACHINE (ALLOWED TRANSITIONS)

**Created:**

- `fundDeal` (client) -> `Funded`
- `cancel` (client) -> `Canceled`

**Funded:**

- `markDelivered` (provider) -> `Delivered`
- `release` (client) -> `Released`
- `refund` (client) -> `Refunded` (only at/after `releaseDeadline`)

**Delivered:**

- `release` (client) -> `Released`
- `refund` (client) -> `Refunded` (only at/after `releaseDeadline`)

**Final states** (no outgoing transitions):

- `Released`
- `Refunded`
- `Canceled`

## 11. SECURITY REQUIREMENTS

- Use SafeERC20 for all ERC20 interactions.
- Use ReentrancyGuard for functions that transfer tokens out:
  - `release`
  - `refund`
  - `rescueToken`
- Apply Checks-Effects-Interactions pattern:
  - validate
  - update status
  - transfer
- Prevent double spend:
  - once `Released`/`Refunded`, no further transfers possible.
- Do not store large strings on-chain; use hashes only.

## 12. EDGE CASES / DEFINITIONS

- **Deal existence:**
  - deal exists if `deals[dealId].client != address(0)`
  - otherwise revert `DealNotFound()`
- **Invalid deadlines:**
  - `releaseDeadline` must be strictly greater than current `block.timestamp` at creation.
- **Token decimals:**
  - `amount` is raw token units; no on-chain decimal conversion.
